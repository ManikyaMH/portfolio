# Manikya M Halingali — Portfolio

Personal portfolio website for Manikya M Halingali, Software Engineer.

🌐 **Live Site:** [https://ManikyaMH.github.io/portfolio](https://ManikyaMH.github.io/portfolio)

## Tech Stack
- Pure HTML5 + CSS3 (no frameworks, no build tools)
- Fully responsive — mobile, tablet, desktop
- Zero dependencies — open `index.html` directly in any browser

## Sections
- Hero — Introduction & contact
- About — Bio, strengths, stats
- Education — Academic timeline
- Projects — 4 featured projects
- Skills — Categorized tech stack
- Certifications — Credentials
- Contact — Reach out links

## Local Development
Just open `index.html` in any browser. No server needed.

## Deployment
Hosted via **GitHub Pages** — any push to the `main` branch auto-deploys.
